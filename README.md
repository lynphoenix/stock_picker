# A股智能选股系统

基于Python的A股智能选股与回测系统，采用事件驱动回测框架，支持多策略切换和全市场历史回测。

## 核心特性

### 模块化架构
- **事件驱动回测引擎** - 高性能回测框架
- **策略系统** - 可插拔策略设计，支持多种交易策略
- **数据管理** - 高效数据缓存与加载机制
- **技术指标** - MA、MACD、KDJ、RSI、BOLL、ATR等19种指标

### 回测功能
- **全市场回测** - 支持5000+股票历史回测
- **行业分类统计** - 按行业分析收益表现
- **风险指标** - 收益率、胜率、最大回撤、盈亏比
- **净值曲线** - 每日净值跟踪与可视化

### 数据系统
- **历史数据** - 2015-2026年完整历史数据
- **股票覆盖** - 5,323只A股（96.6%覆盖率）
- **数据存储** - Pickle格式，按年分文件存储
- **指数数据** - 上证、深证、创业板、沪深300等主流指数

## 快速开始

### 安装依赖

```bash
# 克隆项目
git clone https://github.com/yourusername/stock-picker.git
cd stock-picker

# 安装依赖
pip install -r requirements.txt
```

### 主要依赖

- `akshare` - A股数据获取（东方财富）
- `pandas` - 数据处理
- `numpy` - 数值计算
- `python-dateutil` - 日期处理

## 使用方法

### 1. 运行全量回测

```bash
python backtest_full.py
```

回测参数：
- 回测期间: 2015-2025
- 初始资金: 100,000元
- 最大持仓: 5只股票

### 2. 下载历史数据

```bash
# 下载指定年份历史数据
python scripts/download_market_data.py --year 2024

# 下载最新数据
python scripts/download_latest.py
```

### 3. 计算技术指标

```bash
python scripts/calculate_indicators.py
```

计算指标：
- 移动平均线: MA5, MA10, MA20, MA60, MA120, MA250
- MACD: DIF, DEA, MACD
- KDJ: K, D, J
- RSI: RSI6, RSI12, RSI24
- 布林带: BOLL_UP, BOLL_MID, BOLL_LOW
- 波动率: ATR14

### 4. 查看监控

```bash
# 实时监控数据进度
python scripts/terminal_monitor.py
```

## 策略说明

### 涨停回撤策略 (LimitUpPullbackStrategy)

**入场条件：**
- 涨停后回撤3-7%
- MACD金叉
- 成交量放大

**出场条件：**
- 止盈30%或50%（分批）
- 止损10%
- MACD死叉

**仓位管理：**
- 最多持仓5只股票
- 等权重分配
